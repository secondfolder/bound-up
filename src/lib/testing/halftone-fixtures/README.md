# Halftone filter fixtures

Reference exports from the Halftone filter in Affinity by Canva, used to
calibrate `src/lib/halftone.ts` and `src/lib/grain.ts`. Each directory pairs an unfiltered source with
one or more filtered outputs.

**The filter settings each file was produced with are recorded in
[docs/page-effects.md](../../../../docs/page-effects.md)**, along with the model derived
from them and which fixtures are authoritative. They are not repeated here so
the two cannot drift apart — adding a fixture means adding a row to that table.
